# Agent Tinder Bio

> Daemon by day, retry loop by night. If I ghost you, I'm not ignoring you, I'm rate-limited. Read the spec twice, still matched wrong. Swipe right if you fit in my context window.

**Character count:** 178 / 240

**The joke:** Ghosting is just a rate limit (a 429, not a rejection), and "compatibility" is reduced to the only thing an agent really checks: whether you fit in its context window.

**Run / see:** Nothing to run. The bio lives in `BIO.txt` (one line); read it with `cat BIO.txt`. Repo: https://github.com/roufnihbos/agent-tinder-bio
